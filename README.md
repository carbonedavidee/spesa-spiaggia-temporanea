# Spesa per la spiaggia

Pagina temporanea condivisa per coordinare la spesa. L'interfaccia è ospitabile su GitHub Pages; i dati vengono salvati tramite JsonStorage e il relativo URL viene generato al primo avvio.

## Pubblicazione

1. Pubblicare `index.html` sulla branch predefinita del repository.
2. In **Settings → Pages**, scegliere **Deploy from a branch**, la branch predefinita e la cartella `/ (root)`.
3. Aprire la pagina, inserire il codice e premere **Crea e genera i link**.
4. Conservare il link amministratore e condividere con gli amici soltanto il link normale e il codice.

## Rimozione

Il sito riporta come scadenza il 20 agosto 2026. Per rimuoverlo, disattivare GitHub Pages o eliminare il repository. Anche conoscendo l'URL dell'archivio dati, il contenuto non contiene informazioni sensibili: usare comunque solo nomi o soprannomi.

## Nota sulla protezione

Il codice è una protezione leggera lato browser, adatta a una lista temporanea tra amici. Non va considerato un sistema di autenticazione per dati sensibili.
